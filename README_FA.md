# پروژه MATRОNIX / MATRONIX

این فایل ZIP شامل پروژه آغازین اندروید و فریمور Arduino برای MAT BOT است.

## محتویات
- `app/`: برنامه Android با Kotlin و Jetpack Compose
- `arduino/MAT_BOT/`: کد اولیه Arduino UNO R3
- فایل‌های Gradle برای بازکردن پروژه در Android Studio

## پیش‌نیاز سخت‌افزاری کد آردوینو
این کد با فرض استفاده از HC-05، درایور TB6612FNG و OLED از نوع SSD1306 با رابط I2C نوشته شده است.
نمایشگر ۲ اینچی شما ممکن است SSD1309 یا SPI باشد؛ در آن صورت بخش نمایشگر باید تغییر کند.
برای حالت نگهبان، حسگر HC-SR04 لازم است. خروجی صدا هنوز به سخت‌افزار متصل نشده است.

## سیم‌بندی فرضی
- HC-05 TXD -> Arduino D10
- Arduino D11 -> تقسیم مقاومتی مناسب -> HC-05 RXD
- TB6612: PWMA=D5, AIN1=D7, AIN2=D8, PWMB=D6, BIN1=D4, BIN2=D3, STBY=D2
- OLED I2C: SDA=A4, SCL=A5
- HC-SR04: TRIG=A0, ECHO=A1

زمین (GND) آردوینو، درایور، بلوتوث و منبع تغذیه باید مشترک باشد.
موتورها را هرگز مستقیم به پایه‌های آردوینو وصل نکن.
منبع تغذیه موتورها را مطابق مشخصات موتور و درایور انتخاب کن.
ورودی RX ماژول HC-05 را مستقیم با سیگنال ۵ ولت آردوینو تحریک نکن؛ از تقسیم ولتاژ استفاده کن.

## کتابخانه‌های Arduino
از Library Manager نصب کن:
- Adafruit GFX Library
- Adafruit SSD1306

## ساخت برنامه Android
پروژه را در Android Studio باز کن، Gradle Sync بزن و سپس Build > Build APK(s) را انتخاب کن.
برای اتصال، ابتدا HC-05 را در تنظیمات بلوتوث گوشی Pair کن و سپس از برنامه Connect را بزن.

## محدودیت نسخه اولیه
این یک اسکلت شروع پروژه است، نه نسخه نهایی تست‌شده روی سخت‌افزار واقعی.
پیش از اتصال موتورها، ابتدا بدون چرخ و با ربات مهار‌شده، جهت موتورها و سیم‌بندی را بررسی کن.
نوع دقیق OLED، مدل موتور، ولتاژ منبع تغذیه و مدل درایور باید پیش از استفاده نهایی تأیید شوند.
